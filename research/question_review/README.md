# Question review workspace

`templates/W0_FIRST_WAVE_QUESTION_REVIEW_WORKBOOK_V0_1_0.xlsx` is the immutable,
integrity-checked input template for the 150 first-wave questions.

Do not edit the committed template. Copy it outside `templates/` before adding
real owner, approver, scope, policy, test, evidence, observation-window, or
fail-action information. A green `İNCELEMEYE_HAZIR` cell only means the row is
ready for automated validation; it is not approval, adoption, execution, or
live authority.
